# chronicles-of-time

岁月史书 · Chronicles of Time：一个可进入的静态网页，一本藏在赤岩岩腔中、能改写历史的古书。致敬《成龙历险记》的非官方作品，Kiroween 2026 Costume Contest 方向。

这本书可以改写它记下的事，但每一笔都有代价：史中有代价，书也要从别处取走东西。

## 打开
双击 `index.html` 即可（file:// 直接可用）。不需要服务器、联网或构建步骤。

## 文件
- `index.html`：页面结构，以及岩口、石室、石台的内联 SVG
- `style.css`：全部视觉，包括羊皮纸、皮面封面、光柱、墨脉、改写动画和减少动态
- `world.css`、`world.js`：落笔后的全屏「世界改写」序列，全部由程序生成的 SVG 与 CSS 绘出
- `app.js`：原生 JS，中英文案和三则可改之事内联；负责翻页、改写、预言、代价、改写记录和浮尘 canvas

## 操作
- 入洞：点击画面或按 Enter
- 开书：点书或按 Enter
- 翻页：点页角、按 ← / →，或点底部的「前页 / 后页」
- 切换语言：点书顶的红色书签
- 合书：点「合上书」或按 Esc

### 改写历史
1. 在「可改之事」选一则记载。页边会先写出预言：书猜你会先打开哪一则。猜中或猜错，它都会回应。
2. 左页记载里带红色波浪线的句子可以改写。点它（或 Tab 到它后按 Enter / 空格）。
3. 右页列出两种新写法，和一条「让这件事从未发生」。在某个选项上停留片刻，页边会写出书对你选择的预言。
4. 选好后按住「按住落笔」（鼠标按住，或聚焦后按住空格 / Enter）。按住期间书会抖动，原句模糊散开，石室变暗，连锁后果隐约浮现。
   - 所需时间为 1.4 秒，之后每改一笔多 0.7 秒。
   - 提前松手或只轻点，书会说话，什么也不写。
   - 「让这件事从未发生」会在中途被书拒绝，此后划掉不可再选。
5. 落笔后，原句被划去，新句以蓝黑墨渗入，其后的文字被冲掉，换成连锁后果；墨团从落笔处散开。
6. 记载页的「原载 / 今载」可切换查看改写前后。

### 世界改写
落笔成功后，书页之上展开一幅全屏的古书插画，约 9 秒，几乎不靠文字：
1. 一道墨线从落笔处划开旧世界。
2. 旧世界崩塌：钟楼倾斜并化成墨滴，人影失去面孔后被拉长，天色反相，画面错位切片，页角焦黑。
3. 一片漆黑，伴着心跳。
4. 新世界一笔一笔自己写出来。
5. 代价留在新世界里：光暗下去，有人用墨作眼望着你；墨的笔数越多（0 到 2），画面越暗，窗中的脸越多。

壹「沙下之钟」做了完整的四种结局画面：影子脱落爬行、井消失而空镇鸣钟、天空变色且无人抬头、孩子身后升起第二座钟楼。贰、叁使用通用画面（同样的崩塌与重写）。每个阶段只有一行字幕，同时通过实时区播报结果。

- 跳过：右上角「跳过」按钮或 Esc，直接显示新世界最终画面并回到书。
- 重看：改写记录右页的「重看这一笔」可再次播放该条记录，不会改动记录。
- 减少动态：不播放动画，改为旧世界与新世界的淡入淡出，字幕相同。
- 播放期间石室不可操作（`inert`）；撕页或结束时计时器和 DOM 全部清理。

### 代价
墨只够三笔。按改写顺序，书依次取走：
1. 「书之来历」中的一句话
2. 另一则尚未改写的记载的结尾
3. 石室的光：光柱熄灭，书板透出心跳般的微光，扉页多出一行「你也已被写下。」

每多一笔，书页的墨脉从书脊爬出更远，纸页焦色加深，石室褪色；第二笔起光柱摇曳、浮尘上升。封面纹章上的指针逆转。

### 改写记录
第 5 对页记下每一笔：原文、新文与书取走的东西。点一条，右页显示前后对照和连锁，可跳回该记载的原载或今载。点「撕下此页，归还一切」清空所有改写，书会记下被撕的次数。

系统开启「减少动态」时，翻页、场景切换和改写反馈都改为淡入淡出。

## 素材与字体
- 不含任何图片、音频或字体文件；纹理均由 CSS 渐变和 SVG `feTurbulence` 程序生成，墨脉由固定种子的 SVG 路径生成。
- 字体只用系统字体回退：中文为宋体系（Songti SC / STSong / Noto Serif CJK SC / Source Han Serif SC / SimSun），书的声音用楷体系（Kaiti SC / STKaiti / KaiTi），英文为衬线体（Iowan Old Style / Palatino / Book Antiqua / Georgia）。
- 正文、记载、英文铭文和图案均为原创；中文铭文「既已写下，便将如此。」为需求方提供的译句。
